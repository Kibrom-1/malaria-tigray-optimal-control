# Malaria transmission and optimal control in post-conflict Tigray

Python code accompanying **Mathematical Modeling and Optimal Control of Malaria Transmission in Conflict-Affected Settings: A Case Study of Post-Conflict Tigray, Northern Ethiopia**.

Authors are Teklebirhan Abraha Gebrehiwot, Hilluf Reddu Tegegne and Kibrom Gebrehiwot Gebremeskel, Department of Mathematics, Aksum University, Ethiopia.

The repository contains the model implementation, numerical analyses, supplied numerical outputs and scripts for all ten manuscript figures.

## Upload to GitHub

Extract the ZIP, open this folder, and upload its contents to the repository using Add file then Upload files. Keep the code and figs folders together at the repository root. If GitHub already has a starter README, replace it with this README. The .gitignore file is included for Git clients and can also be added through the browser.

## Installation

Use Python 3.11 or later. Open a terminal in this repository folder and install the tested dependencies.

```bash
python -m pip install -r requirements.txt
```

The tested versions are NumPy 2.3.5, SciPy 1.17.0 and Matplotlib 3.10.8. The full workflow takes several minutes, depending on the computer.

## Reproduce the complete analysis

```bash
python run_all.py
```

The runner stops if a script fails. It recomputes the numerical files in `code/` and creates ten PDF figures and ten PNG figures in `figs/`.

## Generate figures from the supplied numerical outputs

The numerical output files are included to allow plotting without repeating every analysis. Run these commands from the repository folder.

```bash
cd code
python make_figures.py
```

This plotting step also recomputes the reference and control trajectories used in the figures. The complete execution order is documented in [code/README.md](code/README.md).

## Data provenance and interpretation

Figures 1, 2 and 4 use published aggregate surveillance values from Hailemariam et al. (2025), *The impact of a humanitarian crisis on the magnitude of malaria in Tigray, Northern Ethiopia from 2014 to 2024*, Malaria Journal, DOI [10.1186/s12936-025-05366-x](https://doi.org/10.1186/s12936-025-05366-x). Values are embedded in `code/make_figures.py`.

The model uses literature-informed parameters and scenario assumptions. Annual surveillance counts provide context and a plausibility comparison. Relative intervention results are conditional on the model assumptions. The numerical checks do not prove local or global optimality.

Each timing policy uses exactly 90 days of high effort and 58.75 resource-unit days over the year, including the uniform comparator. Endpoint control values influence adjacent integration intervals.
